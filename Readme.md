Steam Games Data Analysis

An exploratory data analysis project on 27,000+ Steam games, uncovering patterns in pricing, ratings, genres, and player engagement — presented through an interactive dashboard.

Overview

This project analyzes the Steam Store Games Dataset to answer questions like: Which genres dominate the market? Do higher prices mean better ratings? Which games offer the best value for money? And which excellent, high-rated games are still flying under the radar?

Unlike a predictive modeling project, this is a pure data analysis project — the goal is to extract clear, actionable insights from the data and present them in an accessible, interactive way.

Features
Interactive dashboard — filter games by genre, price range, release year, and free/paid status, with all charts updating live
Custom-engineered metrics — a satisfaction score, price tiers, and a "value for money" score built from raw data
Hidden Gems discovery — a dedicated analysis surfacing highly-rated games with a small player base that most people have never heard of
Multi-angle exploration — pricing, genres, playtime, developers, release trends, and platform support, each analyzed independently

Dataset
Source: Steam Store Games Dataset (Kaggle)

27,075 games scraped from the Steam store and SteamSpy
Covers releases from 1997 to 2019
Includes pricing, genres, categories, developer/publisher, playtime estimates, review counts, achievements, and estimated ownership ranges

Data Cleaning & Feature Engineering
Filled missing developer/publisher values (fewer than 15 rows affected)
Converted release_date to datetime and extracted release_year
Converted the owners text range (e.g. "1000000-2000000") into a usable numeric owners_midpoint
Built a satisfaction_pct score from positive/negative review counts
Extracted primary_genre from the multi-value genres field
Bucketed games into price_category tiers (Free, Budget, Mid-range, Premium, AAA)

Key Analyses
Pricing — free vs. paid split, price tiers, and their relationship with satisfaction and player reach
Genre trends — which genres are most produced, most played, and most highly rated
Ratings — top and most controversial games, satisfaction distribution
Engagement — playtime patterns, and how achievements relate to time spent
Developers & publishers — most prolific and highest-rated studios
Release trends over time — industry growth and shifting genre popularity by year
Platform & language reach — how multi-platform support relates to player base size
Hidden Gems — excellent, under-the-radar games (high satisfaction, low visibility)
Value for money — playtime-per-dollar ranking of paid games

Running the Dashboard Locally
Install dependencies:
bash
   pip install streamlit plotly pandas
Ensure steam_clean.csv is in the same folder as dashboard.py (generated by running the notebook through the data cleaning and feature engineering steps).
Launch the dashboard:
bash
Streamlit run dashboard.py
The dashboard opens automatically in your browser at http://localhost:8501.

Notes & Limitations
The dataset covers games up to 2019 — it does not reflect more recent releases or current market trends.
The owners field is an estimated range provided by SteamSpy, not an exact figure — analyses using it (like owners_midpoint) are approximations.
Review counts can occasionally be affected by "review bombing" (coordinated negative reviews unrelated to game quality), a known quirk of Steam review data.
